# 项目目录

本目录为每个共建项目提供独立的学习入口。一个项目只维护自己的目标、教程和每周任务。

## 当前项目

- [`yczx_code/`](./yczx_code/README.md)：YCZX Code 学习与共建主线。

## 新项目目录约定

```text
<project-id>/
├─ README.md      项目学习目标、边界和目录说明
└─ tasks/         按周或阶段维护的任务
│  ├─ learning/   面向全体学习者的任务
│  └─ core/       面向核心开发者的任务
```

新增项目的 README 至少说明：

- 项目目标和当前阶段。
- 需要掌握的知识与推荐顺序。
- `tasks/` 中各路线和文件的用途。
- 学习路线、核心开发路线和阶段目标（如适用）。
- 本项目暂时不做什么。

项目 ID 使用简短的小写英文和下划线；不要把多个项目的任务混在同一个目录中。
