# YCZX Code 核心开发路线第 5 周：上下文与可靠循环

> 周期：2026 年 8 月 10 日至 16 日

## 本周结果

让 CLI Agent 在多轮、较长任务和工具失败时仍然可观察、可恢复。

## 学习材料

- `hello-agents`：第七章至第九章，重点是框架、记忆和上下文。
- `learn-claude-code`：`s06_subagent`、`s07_skill_loading`、`s08_context_compact`、`s09_memory`、`s10_system_prompt`、`s11_error_recovery`。

## 开发任务

1. 启动时加载 `AGENTS.md`、项目 README 和当前任务作为按优先级排列的知识。
2. 将会话、工具调用和错误统一记录为可观察事件。
3. 实现基础上下文限制：保留系统规则、最近消息和当前工具结果。
4. 为模型异常、工具异常和达到最大步数设计明确结束状态。
5. 固定 CLI 输出格式，区分用户输入、模型文本、工具调用和错误。

## 验收

- `/context` 能显示会话消息数、工具调用数和当前步数。
- 工具失败后 Agent 不会静默卡住或无限重试。
- 至少有一个长对话和一个工具失败的回归测试。
