# YCZX Code 核心开发路线第 7 周：安全审查与预览版发布

> 周期：2026 年 8 月 24 日至 30 日，9 月 1 日前完成补交

## 本周结果

冻结第一版功能，完成测试、演示和技术复盘，形成可写入简历的真实项目材料。

## 学习材料

- `hello-agents`：第十三章至第十六章选择与代码库分析相关的综合案例。
- `learn-claude-code`：`s15_agent_teams` 至 `s20_comprehensive`，理解后续扩展方向，不在本阶段强制实现。

## 开发任务

1. 完成安全检查：工作区边界、敏感文件、最大步数、API Key 和日志内容。
2. 清理测试、临时输出和本地配置，确保仓库不含密钥、`.env` 或私密数据。
3. 完成端到端 Demo：启动 CLI，分析代码库，展示工具调用和最终回答。
4. 补充架构图、模块说明、非目标和后续路线。
5. 记录固定评测结果和已知失败案例，准备一次技术分享或面试式讲解。

## 预览版验收

- `uv run python -m yczx_code` 可以启动交互式会话。
- 支持多轮对话、只读代码库工具、项目规则加载和可见工具过程。
- `/help`、`/reset`、`/context`、`/quit` 可用。
- 测试覆盖 Agent Loop、工具分发、路径安全、敏感文件和错误状态。
- README 能让其他成员复现，且明确说明它不是完整 Claude Code。

## 明确不做

本阶段不加入文件写入、任意 Shell、多 Agent、插件市场、复杂 GUI 或完整 MCP 运行时。需要这些能力时，另立阶段任务并重新评估安全边界。
