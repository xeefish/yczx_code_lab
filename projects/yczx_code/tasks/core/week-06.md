# YCZX Code 核心开发路线第 6 周：评测与预览版 Alpha

> 周期：2026 年 8 月 17 日至 23 日

## 本周结果

完成可供组内试用的 CLI Agent Alpha，并用固定任务验证行为。

## 学习材料

- `hello-agents`：第十章至第十二章，重点是协议、上下文和评估。
- `learn-claude-code`：`s12_task_system`、`s13_background_tasks`、`s14_cron`，只吸收适合当前范围的设计。

## 开发任务

1. 编写 5～10 个固定代码库分析任务和明确成功标准。
2. 记录成功率、工具调用次数、步数、错误类型和人工观察结果。
3. 补充 CLI 启动、退出、重置、配置缺失和无网络时的错误处理。
4. 编写 README：定位、安装、启动、配置、安全边界、示例和已知限制。
5. 进行一次组内试用，收集不涉及密钥和个人资料的反馈。

## 验收

- 新成员按 README 能启动并完成至少一个任务。
- 固定评测结果可重复运行并保存摘要。
- Alpha 不包含文件写入和任意 Shell 执行。
