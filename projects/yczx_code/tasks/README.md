# YCZX Code 任务目录

## 路线

- [`week-01.md`](./week-01.md) 和 [`week-02.md`](./week-02.md)：前两周共同基础，保留旧路径以兼容已有会议和学习记录链接。
- [`learning/`](./learning/)：面向所有成员的学习路线，重点是理解、运行和复盘。
- [`core/`](./core/)：面向核心开发者的实现路线，重点是设计、实现、测试和发布。

以后新增周任务时，按路线放入对应目录，文件统一命名为 `week-XX.md`。

核心开发任务在本仓库维护，但正式实现提交到 [YCZX Code 正式仓库](https://github.com/yanchuaner/yczx_code)。仅用于个人理解的原型可以放在本仓库 `exercises/yczx_code/<github-id>/week-XX/`；原型不会自动进入正式项目。

## 任务完成等级

- **了解**：读过材料，能解释主要概念。
- **实践**：运行或修改过示例，并保留实际输出。
- **交付**：完成独立作品、测试或可复现 Demo。

学习路线通常要求达到“实践”；核心开发路线的关键任务要求达到“交付”。
