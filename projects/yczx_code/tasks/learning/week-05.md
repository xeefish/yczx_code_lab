# YCZX Code 学习路线第 5 周：记忆、检索与上下文

> 周期：2026 年 8 月 10 日至 16 日

## 学习目标

- 理解短期消息历史、长期记忆和检索上下文的区别。
- 理解上下文窗口、裁剪和信息优先级。
- 认识错误恢复和评估的重要性。

## 学习材料

- `hello-agents`：第七章复习，第八章和第九章重点阅读。
- `learn-claude-code`：`s06_subagent`、`s07_skill_loading`、`s08_context_compact`、`s09_memory`、`s10_system_prompt`、`s11_error_recovery`。

## 必做实践

1. 为一个较长的项目分析任务记录消息增长过程。
2. 设计一个简单的上下文裁剪规则，并说明会丢失什么信息。
3. 为案例增加一个可重复的失败输入，记录 Agent 应如何结束或重试。

## 验收

- 能区分“模型记住了”和“Harness 再次提供了信息”。
- 能说明上下文压缩不能替代任务状态保存。
- 提交至少一个固定输入和预期结果，作为后续评测样例。
