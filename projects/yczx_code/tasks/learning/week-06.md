# YCZX Code 学习路线第 6 周：协议、评估与综合系统

> 周期：2026 年 8 月 17 日至 23 日

## 学习目标

- 了解 MCP、A2A 等协议解决的问题，不急于实现完整协议。
- 理解 Agent 评估中的任务成功、工具正确性、步数和成本。
- 将前几周概念串成一个完整系统图。

## 学习材料

- `hello-agents`：第十章至第十二章。
- `learn-claude-code`：`s12_task_system`、`s13_background_tasks`、`s14_cron`，了解设计目的。

## 必做实践

1. 为一个代码库问答 Agent 设计 5 个固定评测问题。
2. 记录每个问题的成功标准、最大步数和失败原因。
3. 绘制从用户输入到最终回答的完整系统图。

## 验收

- 能说出至少三个 Agent 评估指标及其局限。
- 能解释协议、工具和 Agent Loop 的关系。
- 完成一次小组分享或提交录音、文字讲解稿。
