## 维护原则

- 共用规则只维护一份，避免复制后互相不一致。
- 教程优先使用 Markdown，命令应能直接复制执行。
- 每份教程写清适用环境、前置条件、成功标志和常见错误。
- 会议文件只记录可公开内容，不存放私人备注和成员隐私。
- 发现过时命令或失效链接时，通过文档 PR 修正并写明验证方式。
